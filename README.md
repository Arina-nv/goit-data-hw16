# Fashion MNIST Classifier

Вебзастосунок на Streamlit для класифікації зображень одягу з використанням нейронних мереж CNN та VGG16.

## Функціональність

Застосунок дозволяє:

- обрати модель CNN або VGG16;
- завантажити зображення одягу;
- переглянути завантажене зображення;
- отримати передбачений клас;
- переглянути ймовірність передбачення;
- переглянути ймовірності для всіх 10 класів Fashion-MNIST;
- переглянути графіки Accuracy та Loss під час навчання моделі.

## Використані моделі

### CNN

Власна згорткова нейронна мережа, навчена на датасеті Fashion-MNIST протягом 15 епох.

### VGG16

Модель VGG16 з попередньо навченими вагами ImageNet. Було виконано transfer learning та fine-tuning останніх шарів моделі.

Підсумкова тестова точність VGG16 після fine-tuning — приблизно 92,79%.

## Запуск застосунку

Встановити залежності:

```bash
pip install -r requirements.txt
```

Запустити Streamlit:

```bash
streamlit run app.py
```

Після запуску застосунок буде доступний у браузері.

## Файли проєкту

- `app.py` — код Streamlit-застосунку.
- `cnn_model.keras` — навчена CNN-модель.
- `cnn_history.json` — історія навчання CNN.
- `vgg16_model.keras` — навчена модель VGG16.
- `vgg16_history.json` — історія навчання VGG16.
- `requirements.txt` — список необхідних Python-бібліотек.
